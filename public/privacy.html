Data handling

This workspace is intended for one authorized team. All active members can read all matters, source materials and saved runs. Administrators manage accounts. A draft run sends the selected matter context, sources and earlier drafts for that skill to the configured OpenAI API project. Calculator runs execute locally on the server and make no network requests. The application requests store:false for model responses; this is not a promise of zero retention by OpenAI. Saved source and run snapshots remain in the workspace database and exports until removed through an administrator managed retention process. This version has no automated retention, source deletion or matter deletion interface. Set a retention policy and backup access rules before using nonpublic materials. Source text and model output are not intentionally written to request logs. The session cookie is required for sign-in. No advertising or analytics cookies are used. Contact your workspace administrator for access, correction or removal requests. This is an operational description, not a representation of compliance or privilege.
